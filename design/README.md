# SafeListing design artifacts

Keep OpenDesign exports, thumbnails and reusable designs here with appropriate rights. Root `DESIGN.md` and `AGENTS.md` are canonical. `OPEN_DESIGN_BRIEF.md` describes approved product scope; pillars stay labelled planned until implemented. Keep legacy mobility distinct. Record integration, AI use, provenance and handoff in Git. No agent-specific repository or bundled OpenDesign runtime.

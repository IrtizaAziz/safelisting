# Urbanova — shared rules for Antigravity

Read and follow repository-root `AGENTS.md` and `DESIGN.md` before making edits. These are also the rules used by Codex and OpenDesign. In case of conflict, defer to the current team's recorded decisions in `docs/DECISIONS.md`, and ask before changing the final concept.

- Work in this Git repo; do not create an independent Antigravity-only project copy.
- Check `git status` before edits. Coordinate exclusive access if Codex uses the same working tree.
- Use sample data only with explicit DEMO/SIMULATED labels.
- Run `npm run check`, and document results in `docs/HANDOFF.md`.
- For UI, follow `DESIGN.md`; for handoff use `docs/HANDOFF.md`.

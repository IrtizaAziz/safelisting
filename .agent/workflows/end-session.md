# End a hackathon development session

1. Run `npm run check`; list any blockers if unavailable.
2. Update `docs/HANDOFF.md` with completed work, modified paths, validation, remaining risks and next action.
3. Record irreversible decisions in `docs/DECISIONS.md`.
4. Check for secrets, PII, misleading impact claims and unlicensed assets.
5. Commit or open a pull request. Share branch/commit and confirm `git status` is clean before another agent edits the workspace.

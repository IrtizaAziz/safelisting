# Start a hackathon development session

1. Read `AGENTS.md`, `DESIGN.md`, `docs/DECISIONS.md`, `docs/HANDOFF.md`.
2. Inspect `git status`, current branch, and recent commit history.
3. Check whether the PEOPLE concept has been officially selected.
4. State planned changes; avoid touching files another agent owns.
5. Install dependencies if necessary (`npm install`), then run `npm run check` before/after edits.
